# Category and VAT code

- Category — which expense account a purchase books to: `CostCategoryCode`, listed by `billit categories list`.
- VAT code — how its VAT is treated: `VentilationCode`, from Billit's ventilation-code tables, cost side and sales side, both indexed in `https://docs.billit.be/llms.txt`.
- The category and the VAT code are two separate choices; settling one settles nothing about the other.
- Both sit on the supplier, where they only prefill documents entered by hand, and on each order.
- Which treatment a document is owed → research it for that case, from the document and primary sources; never carry one case's answer to another as a rule.
