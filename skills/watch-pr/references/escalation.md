# Pause — when the watch hands back

- A pause ends the watch; the item is left to the user, who relaunches with /watch-pr `<N>` after acting.

## Pause conditions

- A bot thread neither fixed nor refuted with quoted evidence, and owned by no other ticket.
- A `--force-with-lease` refused: the remote moved.
- A CI failure with no code root — infra, a flake.
- A conflict whose two sides cannot both survive the resolution.
- The 6th fixable line (`CONFLICT`, `NEW_COMMENTS`, `CI_RED`) in a row without a `CLEAN` between; the session counts its own.
- A verdict outside the verdict table; never guess an action for it.

## How to pause

1. A rebase or merge in progress → `--abort` it, leaving the branch as last pushed.
2. `PushNotification`: the condition, the PR, and one pointer — thread URL, red check, fixable-line count.
3. Print the same context inline.
4. A watcher still armed → `TaskStop <task id>`.
5. End the turn.
