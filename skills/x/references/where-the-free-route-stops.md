# Where the free route stops

## A long-form article

- The body past `article.preview_text` needs a logged-in session → a persisted session from a `yann:browser-pilot` `MODE: DISCOVERY` dispatch.

## A protected or deleted account

- Both answer 404, exit `3`.
- Deleted → stays unreadable.
- Protected → needs that same logged-in session, and only where the account's owner has granted the user access.

## The official X API

- Reading another account's post starts at the Basic tier (~$200/month); the free tier writes posts and reads the authenticated user's own timeline.
- It is the answer to publishing, never to reading one link.
