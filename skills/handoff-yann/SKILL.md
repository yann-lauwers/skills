# Handoff

- Pick the format from § Formats by the request's phrasing; ambiguous → the shape the phrasing leans toward — a named audience → teammate guide, "pick this up later" → session resume, a chat surface → chat post — and name the shape taken and the other two in one line.
- The matched format decides the document's sections, length and shape.
- The argument names the next session's focus → shape the document around it.
- Write it to `$TMPDIR`, named by a short kebab-case slug of its focus.
- A handoff on the same subject already in `$TMPDIR` → update it in place; no `v2` file, revision-history section or update comment.
- No metadata: no HTML comment, no `created:` / `branch:` / `source:` line, no "generated by" footer.
- Reference an existing artifact — a spec, plan, ADR, issue, commit, diff — by path or URL, never by copying its content.
- Redact PII.

## Output

- Write the file before any reply text; the reply is its absolute path and a 2–3 sentence summary, never the body, whatever its size.
