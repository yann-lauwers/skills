# ACT — these change state rather than voting

Entry requirement for this tier: the action is scoped by recorded ownership, never by a search of live system state; a check that must read live state names, in its own row, the declared spec bounding the read and its rate — none does today.

| id | component | event | acts when | class | rollout |
| --- | --- | --- | --- | --- | --- |
| `precompact-capture` | `precompact-capture.py` | PreCompact | a compaction is about to replace the conversation | ACT | `ENFORCING` — writes state, emits nothing: `<session>.json`, read by `precompact-rearm` at the next prompt, and a never-overwritten `<session>.pc<epoch>.json`, holding `skills` (Skill-tool loads from `read-log/<session>`), `canon`, `artifacts`, `pages` (both addresses of each, resolved from `<group>/registry.json`; a missing half delivered as `NO LOCAL COPY`), `transcript_path` and the seam's identity; it reads every feed, then archives the read-log to `<session>.pc<n>`. Ownership is the payload's session id alone. |
| `stopfailure-resume` | `stopfailure-resume.py` | StopFailure | a turn ends on an API error of any type: after a detached settle (`STOPFAILURE_RESUME_SETTLE_SECONDS`, default 5, the proof's override), it reads the session's transcript back to the last prompt; that prompt is not its own resume line, or the model wrote any non-synthetic output after it → types the resume line into the session's cmux seat (`cmux paste --submit`, which refuses over a draft or an open dialog) — `injected`; its resume line got no output → banner through `nx-notify.sh`, nothing typed — `warn` `reason=resume-spent`; paste refused → banner — `warn` `reason=paste-refused`; no cmux seat or no readable transcript → banner — `abstain` | ACT | `RECORDING` — StopFailure output is ignored, so typing into the seat is the only route back into the turn |
